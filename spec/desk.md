# Стол: сроки годности файлов

Версия 1, 2026-11-08. Тестовые случаи — `spec/desk-cases.tsv`, эталон — `python3 spec/tools/check-desk.py`.

Стол следит за тремя папками, которые человек наполняет сам: Загрузки, Рабочий стол и папка скриншотов. У каждого файла там есть срок. Когда срок выходит, Стол сам убирает файл и пишет об этом; вернуть можно одним действием. Ничего не удаляется.

## Какие файлы

- **Папки.** `~/Downloads`, `~/Desktop` и папка скриншотов. На Mac папка скриншотов — `com.apple.screencapture location`, по умолчанию Рабочий стол; на Windows — `Изображения\Снимки экрана`. Если папка скриншотов совпадает с одной из двух других, это одна папка.
- **Только верхний уровень.** Вложенные папки и их содержимое не трогаем: человек их завёл сам, значит разобрал.
- **Пропускаем** (стадия `skip`):
  - скрытые файлы (имя начинается с `.`) и `desktop.ini`, `Thumbs.db`, `Icon\r`;
  - недокачанное: расширения `crdownload`, `download`, `part`, `partial`, `opdownload`, `tmp`;
  - ярлыки, псевдонимы и символические ссылки (`link`);
  - пакеты и папки: всё, что на диске каталог (`dir`), включая `.app`;
  - исключённое человеком: файл или расширение (`excluded`).
- **Скриншот** (`screenshot`) — на Mac файл с атрибутом Spotlight `kMDItemIsScreenCapture` или лежащий в отдельной папке скриншотов; на Windows — файл в папке скриншотов.

## Сроки

| Что | Срок, дней |
|---|---|
| обычный файл | 30 |
| скриншот | 14 |
| файл с личными данными (`personal`: детектор Замазки нашёл паспорт, карту, СНИЛС и т. п.) | 3 |

Если человек на карточке нажал «Оставить» (`kept`), у файла с личными данными обычный срок (30 или 14). Сроки меняются в настройках.

## Возраст и стадии

- **Начало отсчёта** — позднейшая из двух дат: когда файл появился в папке (`added`; на Mac `NSURLAddedToDirectoryDateKey`, на Windows время создания) и когда Стол включили (`enabled`). Иначе в первый же день Стол унёс бы годы старых Загрузок разом. Дата изменения для отсчёта не годится: скачанный файл часто приходит со старой датой.
- **Возраст** — число полных календарных дней по местному времени от начала отсчёта до сегодня (`today`).
- **Стадия**:
  - `fresh`, если `возраст × 3 < срок × 2` (первые две трети срока);
  - `aging`, если ещё `возраст < срок`; видна в окне Стола; файл при этом не меняется, иконки в Finder и Проводнике не трогаем;
  - `expired`, если `возраст ≥ срок`.
- **Действие** для `expired`: `move`, но `hold`, если файл менялся вчера или сегодня (`modified ≥ today − 1`): с ним, видимо, ещё работают. Для остальных стадий — `none`.

## Копии Перепечатки

Файл с меткой копии (`reprint.md`, «Метка копии»: на Mac атрибут `com.vldvr.redakciya.reprint`, на Windows поток `redakciya.reprint`) идёт мимо сроков выше:

- отсчёт — время выдачи из метки, не дата в папке и не включение Стола; срок — ровно 24 часа (`reprint-cases.tsv`, случаи `spoil`);
- до 24 часов — `fresh`, после — `expired` с действием `move`; `hold` нет;
- детектор Замазки, карточка «Похоже на паспорт», `kept` и сдача в Архив к копии не применяются: она уходит в «Убрано со стола»;
- метка не читается — обычный файл.

## Перенос

- **Куда.** Пока нет Архива — в обычную папку `~/Редакция/Убрано со стола/ГГГГ-ММ/` (месяц переноса), без шифрования. Когда появится Архив, её содержимое переедет туда, а Стол станет убирать прямо в Архив.
- **Имя.** Прежнее. Если такое уже есть — `имя 2.расш`, `имя 3.расш` и дальше, как в Finder.
- **Как.** Переименованием в пределах диска; если папки на разных томах — копия, сверка размера, затем исходник уходит. Перед переносом файл проверяется ещё раз: на месте, не изменился с момента оценки.
- **Когда.** При запуске программы и раз в час. Один проход переносит все `move`.
- **Журнал.** Каждый перенос пишется в свой файл (Mac — `~/Library/Application Support/Redakciya/desk-journal.jsonl`, Windows — `%APPDATA%\Redakciya\desk-journal.jsonl`): дата, откуда, куда. Только пути, без содержимого.
- **Отчёт.** В меню строка «Стол убрал: N» за последний проход и «Вернуть на место». В утреннем выпуске — рубрика Стола.
- **Вернуть.** Файл переезжает обратно в ту папку, откуда ушёл, с тем же правилом имени. Отсчёт для него начинается заново с дня возврата.

## Доступ к папкам

macOS (и Windows с «Контролируемым доступом к папкам») спрашивает про каждую папку при первом чтении. Поэтому Стол не читает папки, пока человек не нажал «Разрешить» в окне знакомства или в настройках; по этой кнопке программа один раз читает каждую папку, и вопросы системы появляются тогда же. Если доступа нет, в настройках строка «нет, Стол не работает» и кнопка, открывающая нужный раздел системных настроек.

## Личные данные

- **Что считается.** Документы: паспорт, СНИЛС, ИНН, полис ОМС, банковская карта, номер счёта. Телефон, почта, имя, адрес на скриншоте срок не сокращают: они почти на каждом снимке переписки.
- **Какие файлы.** Только картинки (`png`, `jpg`, `jpeg`, `heic`, `heif`, `tif`, `tiff`, `webp`, `bmp`, `gif`), не пропущенные по правилам выше. PDF и сканы в PDF — позже.
- **Детектор.** Mac — ZamazkaKit (общая библиотека с Замазкой, Vision OCR, всё на устройстве). Windows — свой, на Windows OCR, с теми же видами документов. Проверяем по одной картинке в фоне.
- **Кэш.** Ответ хранится по пути и дате изменения в своей папке (`desk-personal.json`): только виды найденного, без распознанного текста. Изменённый файл проверяется заново.
- **Карточка.** Для файла, появившегося за последние сутки, — «Похоже на паспорт» (или «на СНИЛС», «на банковскую карту»…): имя, папка, размер, что найдено; текст «Стол уберёт его через N дня в «Редакция/Убрано со стола». Если файл нужен, оставьте его: срок станет обычным.» Кнопки «Оставить» (`kept`) и «Убрать сейчас». После переноса — «Убрано со стола», «Вернуть на место», «Готово». Когда появится Архив, «Убрать сейчас» станет «Сдать в Архив», как в макете.

## Окно Стола

Список файлов со сроком, по возрастанию остатка: «через N дней», «уйдёт завтра», «уйдёт при следующем проходе», «ждёт: файл менялся». Маркер — только на файлах в стадиях `aging` и `expired`. Под именем папка и вид («скриншот», «документ»). У файла: «Убрать сейчас», «Не трогать» (файл исключён по пути навсегда), «Показать в Finder». Ниже «Убрано недавно» — последние переносы, файл которых ещё в «Убрано со стола», с кнопкой «Вернуть». Сверху сводка: «На столе N файлов. На этой неделе уйдут: M.»

## Решено и снято

- Бледных иконок нет: `NSWorkspace.setIcon` пишет в файл расширенные атрибуты, и они уезжают вместе с файлом. Стадия `aging` видна только в окне Стола.
