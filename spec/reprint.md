# Перепечатка

Версия: v1, 2026-11-09. Решено 2026-11-09: журнал — файл age в Архиве; копия выдаётся перетаскиванием и кнопкой «В Загрузки»; «портится» значит, что Стол через сутки убирает копию из Загрузок в «Убрано со стола».

Эта спецификация общая для Mac и Windows. Обе платформы обязаны давать одинаковые результаты на `spec/reprint-cases.tsv`. Эталонная проверка — `python3 spec/tools/check-reprint.py` (только стандартная библиотека Python).

Связано: код выдачи и вёрстка копии — `issue-code.md`; Архив и ключи — `archive-format.md`; сроки Стола — `desk.md`.

## Что делает

Оригинал не выходит из Архива. Наружу уходит копия: подпись «Для: …», код выдачи, лишние поля закрыты Замазкой, метаданных нет. Каждая выдача записывается в журнал. Копия в Загрузках через сутки уходит со стола. По копии, всплывшей где-то ещё, журнал находит, кому её отдавали.

## Выдача

1. В окне Архива у документа — «Перепечатать…». Открывается лист Перепечатки. Документ и журнал открываются **одним** подтверждением Touch ID (Windows Hello): один контекст подтверждения на весь лист.
2. В листе: поле «Для», под ним последние назначения из журнала (до пяти, свежие первыми); найденные Замазкой поля — переключатели, по умолчанию все выключены; превью копии с кодом.
3. Отдать копию:
   - **перетащить превью** в мессенджер или любое окно, принимающее файлы. На Mac — обещание файла и готовый `public.file-url` в одном элементе (режим «Оба»), на Windows — `CF_HDROP` + `FileGroupDescriptorW` + `FileContents`;
   - **«В Загрузки»** — файл ложится в Загрузки и показывается в Finder (Проводнике).
4. Запись в журнал появляется, когда копия действительно отдана: приёмник принял перетаскивание (операция не «нет») или файл записан в Загрузки. Отменённое перетаскивание журнал не трогает, код остаётся за листом и уходит на следующую выдачу.
5. После выдачи лист даёт новый код: две копии с одним кодом не бывают.

Перепечатка работает с картинками (JPEG, PNG, HEIC, TIFF, WebP, BMP, GIF — первый кадр) и PDF. Остальное: «Перепечатать можно картинку или PDF».

## Назначение («Для»)

Человек пишет назначение свободно: «аренда, Петров». Нормализация, по порядку:

1. Знак `№` удаляется: назначение попадает в узор, и «№ X5SR» в нём читалось бы как код выдачи.
2. Управляющие символы удаляются, любые пробельные серии (с переводами строк и табуляцией) становятся одним пробелом, края обрезаются.
3. Приставка «для» в начале, с двоеточием или без, в любом регистре, удаляется вместе с пробелами после неё: строка на копии сама начинается с «Для:».
4. Хвостовые `,` `.` `;` `:` и пробелы удаляются.
5. Пусто — выдать нельзя: «Напишите, для кого копия». Длиннее 60 знаков — «Не длиннее 60 знаков».

Регистр не меняется. На копии: «Для: <назначение>, <дд.мм.гггг>», в узоре — «для: <назначение>, № <код>».

## Код

По `issue-code.md`: 4 знака алфавита, случайный, отличается от **каждого** кода журнала минимум в двух позициях. Журнал — один на владельца, все устройства пишут в один файл (синхронизации в v1 нет, см. «Не решено»). Если за 10 000 попыток код не нашёлся — ошибка «Журнал выдач заполнен».

## Замазка

Детектор Замазки (ZamazkaKit на Mac) ищет поля на картинке и на каждой странице PDF. Каждое найденное поле — переключатель с видом («Номер паспорта», «Дата рождения»…), по умолчанию выключен: что лишнее, решает человек, получатель аренды обычно должен видеть номер паспорта. Включённые поля закрашиваются сплошной тушью `#16181B` до вёрстки копии: узор и полоса ложатся поверх закраски. Закраска — новый растр, под ней ничего не остаётся.

## Копия

- **Картинка** → JPEG, качество 0,88. Длинная сторона больше 4000 px уменьшается до 4000.
- **PDF** → PDF той же длины: каждая страница растрируется (длинная сторона 2400 px), получает Замазку и вёрстку копии и ложится картинкой на свою страницу. Текстового слоя в копии нет.
- **Вёрстка** — `issue-code.md`, «Вёрстка кода на копии», для каждой страницы.
- **Имя файла** — `Копия <код>.jpg` или `Копия <код>.pdf`. Ни исходного имени, ни назначения в имени нет. Если в папке имя занято — `Копия <код> 2.jpg`, как в Столе.
- **Метаданные.** Копия рисуется заново, поэтому из оригинала в неё не попадает ничего: ни EXIF, ни GPS, ни дат съёмки, ни XMP, ни имени. В JPEG допустимы только служебные поля, которые ImageIO пишет сам: размер в пикселях, цветовое пространство, ориентация 1. В PDF словарь Info содержит не больше чем `Producer`, `CreationDate`, `ModDate`; `Title`, `Author`, `Subject`, `Keywords`, `Creator` пусты или отсутствуют, XMP нет.
- **Метка копии.** На файле — атрибут, по которому Стол узнаёт свою копию: на Mac расширенный атрибут `com.vldvr.redakciya.reprint`, на Windows поток NTFS `redakciya.reprint`. Значение — UTF-8 `<код> <время выдачи ISO 8601 UTC>`, например `H7RK 2026-11-09T12:00:00Z`. В самой картинке метки нет.

## Журнал выдач

Файл `~/Редакция/Архив/issues.age` (на Windows `%USERPROFILE%\Редакция\Архив\issues.age`) — обычный файл age v1 для тех же получателей, что документы Архива: ключ восстановления и ключи устройств. По 12 словам журнал открывает штатный `age`. Внутри — JSON:

```
{
  "format": 1,
  "issues": [
    {"code": "H7RK", "doc": "<id документа>", "title": "Паспорт РФ", "for": "аренда, Петров",
     "at": "2026-11-09T12:00:00Z", "via": "drag" | "downloads", "app": "ru.keepcoder.Telegram" | null,
     "file": "Копия H7RK.jpg"}
  ]
}
```

- `title` — название документа на момент выдачи: запись понятна, даже если документ потом убран из Архива.
- `app` — кто принял перетаскивание: на Mac bundle id приложения под курсором при отпускании, на Windows имя exe владельца окна; `null`, если не узнать, и для «В Загрузки».
- Записи только добавляются. Журнал переписывается целиком через временный файл и переименование; если старый журнал не открылся, новый не пишется: «Журнал выдач не открылся».
- Журнала нет — он создаётся при первой выдаче. При восстановлении по 12 словам журнал перешифровывается для нового устройства вместе с документами.

## Порча копии

Копия, отданная в Загрузки, живёт сутки. Её убирает Стол (`desk.md`, флаг `reprint`):

- копия узнаётся по метке; время отсчёта — время выдачи из метки, а не дата в папке;
- копия испорчена, когда `сейчас − выдана ≥ 24 ч`; `hold` для неё нет (её никто не правит), детектор Замазки и карточка «Похоже на паспорт» её не трогают, в Архив она не сдаётся;
- испорченная копия переносится в «Редакция/Убрано со стола», как остальное старьё: ничего не удаляется, вернуть можно.

Если Стол выключен или у него нет доступа к Загрузкам, копия остаётся: лист Перепечатки говорит «Стол уберёт копию из Загрузок через сутки», только когда Стол может это сделать, иначе «Копия останется в Загрузках: Стол выключен».

Копии для перетаскивания пишутся в свою папку кэша (`~/Library/Caches/com.vldvr.redakciya/Reprint/`) и стираются оттуда при запуске и через сутки: мессенджер к этому времени давно забрал свой экземпляр.

## Поиск по копии

В окне Архива, вкладка «Выдачи»:

- **Поле поиска.** Запрос из четырёх знаков, который после нормализации `issue-code.md` (регистр, кириллица, двойники) состоит из знаков алфавита и неразобранных, ищется как код: по правилу «Ввод руками» (как слово после №). Иначе — подстрока без учёта регистра, «ё» = «е», в «Для» и в названии документа. Результаты — свежие первыми.
- **Бросить копию.** Картинку или PDF бросают в окно (или выбирают «Найти по копии…»). Распознавание текста (Vision на Mac, `Windows.Media.Ocr` по `issue-code.md` на Windows), строки и до трёх вариантов на строку — в читатель кода `issue-code.md`. Ответ: запись журнала; «Несколько похожих: H7RK, H7RX» без выбора наугад; или «Код не найден».
- Журнал зашифрован, поэтому вкладка «Выдачи» открывается с Touch ID и держит журнал в памяти, пока открыто окно.

## Тестовые случаи

`spec/reprint-cases.tsv`, колонки:

| Колонка | Что |
|---|---|
| `id` | имя случая |
| `kind` | `purpose`, `code`, `name`, `spoil`, `search` |
| `input` | вход |
| `journal` | для `code` — коды через запятую; для `name` — занятые имена через ` \| `; для `search` — записи `код:для:название` через ` \| `; иначе пусто |
| `expect` | ожидаемое; `—` — отказ |
| `note` | зачем случай |

- `purpose`: `input` — то, что ввёл человек (`\n`, `\t` — перевод строки и табуляция); `expect` — назначение или `—`.
- `code`: `input` — кандидат; `expect` — `ok` или `—`.
- `name`: `input` — `<код> <jpg|pdf>`; `expect` — имя файла.
- `spoil`: `input` — `<выдана> <сейчас>` в ISO 8601; `expect` — `fresh` или `expired`.
- `search`: `input` — запрос; `expect` — коды найденных записей через запятую в порядке журнала, `—` — ничего.

## Не решено

- Журнал на нескольких устройствах: в v1 второе устройство появляется только по 12 словам, и журнал общий через папку. Одновременная выдача с двух устройств может потерять запись.
- Перепечатка документов кроме картинок и PDF (Word, Pages).
- Как Windows показывает лист и превью для перетаскивания (Slint).
